Getting started

This tutorial builds a small Verilog design, drives it from Julia and records a waveform. It uses the 4-tap moving-average filter from examples/filter.v:

module filter (
    input  wire       clk,
    input  wire [7:0] in_data,
    output reg  [7:0] out_data
);

On every rising edge of clk it shifts in_data into a 4-entry history and outputs the average of the previous four samples.

Build and load the design

load_dut runs Verilator, compiles the result and loads it. Builds are cached, so running it again with the same sources is instant.

using VeriJul

src = joinpath(pkgdir(VeriJul), "examples", "filter.v")
dut = load_dut(src, "filter"; build_dir=mktempdir())
DUT(filter, 3 ports)
  input   clk              1 bit
  input   in_data          8 bits
  output  out_data         8 bits

The DUT shows its ports. You can also list them with ports:

ports(dut)
3-element Vector{HardwarePort}:
 HardwarePort("clk", :in, 1)
 HardwarePort("in_data", :in, 8)
 HardwarePort("out_data", :out, 8)

Drive the clock

A Simulator owns simulation time and toggles the clk input in a background task once you call start_clock!. By default the clock has a half period of 5 time units, so rising edges arrive every 10.

sim = Simulator(dut)
start_clock!(sim)
Task (runnable, started) @0x00007fc2e2ba5a50

@tick waits for rising edges. Set an input, wait, and read the output:

dut.in_data = 0xFF
for cycle in 1:6
    @tick sim
    println("t = ", sim.time, "   out_data = ", dut.out_data)
end
t = 20   out_data = 63
t = 50   out_data = 255
t = 80   out_data = 255
t = 110   out_data = 255
t = 140   out_data = 255
t = 170   out_data = 255

The output ramps up over four cycles as the history fills with 0xFF, one cycle later than you might expect because out_data is itself a register.

Inputs take any integer and are truncated to the port width, just like a Verilog assignment:

dut.in_data = 0x142    # 9 bits; only the low 8 are kept
dut.in_data
0x42

Record a waveform

Call enable_trace! before simulating to write a VCD file. Each clock edge adds a sample at sim.time. The file is flushed when the design is destroyed.

stop_clock!(sim)
destroy!(dut)

dut = load_dut(src, "filter"; build_dir=mktempdir())
vcd = joinpath(mktempdir(), "filter.vcd")
enable_trace!(dut, vcd)

sim = Simulator(dut)
start_clock!(sim)
for x in (0x10, 0x80, 0xFF, 0x00, 0x40)
    dut.in_data = x
    @tick sim 2
end
stop_clock!(sim)
destroy!(dut)

filesize(vcd)
1368

Open the file in GTKWave or Surfer to see clk, in_data, out_data and the internal shift register.

Clean up

Always stop the clock before destroying a design: the clock task calls into the model on every edge. stop_clock! waits for that task to finish. A design that is garbage-collected is destroyed automatically, but calling destroy! yourself makes sure the waveform is written.
