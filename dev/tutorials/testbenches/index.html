Self-checking testbenches

Printing values is fine for exploring, but tests should check themselves. This tutorial drives the moving-average filter from Getting started with random data and compares every output against a model written in Julia.

A reference model

The filter outputs the average of the four samples taken before the current edge, rounded down:

function reference(history)
    last4 = history[max(end - 4, 1):end-1]       # samples from the previous 4 edges
    return UInt8(sum(Int, last4; init=0) ÷ 4)
end

Comparing against the design

Each iteration sets an input, waits for the rising edge that samples it, and checks the output. @testset and @test come from Julia's standard Test library, so this runs unchanged under Pkg.test().

using VeriJul, Test, Random

src = joinpath(pkgdir(VeriJul), "examples", "filter.v")
dut = load_dut(src, "filter"; build_dir=mktempdir())
sim = Simulator(dut)
start_clock!(sim)

# Flush the history with zeros so the design and the model agree
dut.in_data = 0
@tick sim 5

Random.seed!(1)
history = zeros(UInt8, 4)
@testset "filter matches reference" begin
    for _ in 1:200
        x = rand(UInt8)
        dut.in_data = x
        @tick sim
        push!(history, x)
        @test dut.out_data == reference(history)
    end
end

Testbenches as tasks

@testbench defines a function and a launch_<name>(sim) that runs it as a task. That's useful when several things should happen in parallel, for example a driver and a monitor:

@testbench function driver(sim)
    for x in (0x40, 0x40, 0x40, 0x40, 0x00)
        sim.dut.in_data = x
        @tick sim
    end
end

@testbench function monitor(sim)
    seen = UInt8[]
    for _ in 1:8
        @tick sim
        push!(seen, sim.dut.out_data)
    end
    return seen
end

d = launch_driver(sim)
m = launch_monitor(sim)
wait(d)
fetch(m)

fetch returns the monitor's result once it finishes. If a task throws, the error is rethrown by wait/fetch, so failures are never silently lost.

Don't hang: timeouts and stopped clocks

A testbench waiting for an edge that never comes would hang forever. Two things prevent that:

  • timeout (wall-clock seconds) on tick or @tick throws a TickTimeout.
  • stop_clock! wakes every waiting task with a ClockStopped error, and tick throws ClockStopped if the clock isn't running.
try
    @tick sim 10^9 timeout=0.5      # far more cycles than 0.5 s allows
catch err
    err
end
TickTimeout(0.5)
stop_clock!(sim)
try
    @tick sim
catch err
    err
end
ClockStopped("the simulator clock is not running; call start_clock!(sim)")

Resetting a design

Designs with a reset input can use reset!, which holds the reset for a number of rising edges and then releases it:

reset!(sim)                                  # port :rst, active high, 2 cycles
reset!(sim, :rst_n; active_high=false, cycles=4)

The clock must be running. The next tutorial uses it.
