VeriJul.jl

VeriJul lets you write hardware testbenches in Julia. It compiles a Verilog design with Verilator, gives you its ports as ordinary Julia properties, and drives the simulation from Julia tasks, so you can check hardware against reference models, random stimulus and everything else in the Julia ecosystem.

using VeriJul

dut = load_dut("filter.v", "filter")      # build (cached) and load
sim = Simulator(dut)                      # drives the `clk` input
start_clock!(sim)

dut.in_data = 0xFF
@tick sim 6                               # wait for 6 rising edges
dut.out_data                              # 0xff

Features

  • One-call builds with build caching, multiple source files, include directories, $`define$s and parameter overrides.
  • Named port access: dut.port = value and dut.port, for any width, including ports wider than 64 bits (as BigInt).
  • Clocks and time: multiple clocks with their own periods and phases, @tick sim n, reset helpers, and timeouts so a stuck testbench fails instead of hanging.
  • Waveforms: VCD tracing you can open in GTKWave or Surfer.

Requirements

  • Julia 1.10 or newer
  • Verilator 4.200 or newer on your PATH (or set VERIJUL_VERILATOR to its path)
  • A C++17 compiler (g++ or clang++; set CXX to pick one)

VeriJul is tested on Linux and macOS. Windows is not supported yet.

# Ubuntu / Debian
sudo apt-get install verilator g++
# macOS
brew install verilator

Installation

using Pkg
Pkg.add("VeriJul")
