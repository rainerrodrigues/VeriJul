API

Building

VeriJul.Builder.build_dut — Function
build_dut(verilog_file, top_module; build_dir="./build", verbose=false) -> (lib_path, bindings_path)

Verilates verilog_file with top_module as the top, generates bindings and compiles everything into a shared library. Returns the library path (load it with VerilatedModel) and the path of the generated bindings.jl (load it with include).

build_dir is deleted and recreated. Set the CXX environment variable to choose the C++ compiler (default g++, or c++ on macOS).

source
VeriJul.Builder.verilator_version — Function
verilator_version() -> VersionNumber

Returns the version of the verilator executable on PATH, or throws an error explaining how to install it.

source
VeriJul.Builder.HardwarePort — Type
HardwarePort(name, direction, width)

A top-level port of a Verilated design. direction is :in or :out (inout ports are treated as :in), width is the bit width.

source
VeriJul.Builder.extract_ports — Function
extract_ports(header_path) -> Vector{HardwarePort}

Reads the ports of a Verilated model from its generated V<top>.h header.

source
VeriJul.Builder.generate_bindings — Function
generate_bindings(ports, module_name) -> (cpp_code, jl_code)

Generates the C++ shim exposing the model through a C ABI, and the Julia AutoBindings module that wraps it (set_<port>! / get_<port>).

source

Models

VeriJul.Interop.VerilatedModel — Type
VerilatedModel(lib_path, create_sym=:top_create)

Loads the shared library built by build_dut and instantiates the model. The model is freed automatically when garbage-collected, or explicitly with destroy!.

source
VeriJul.Interop.eval_step! — Function
eval_step!(model, time)

Evaluates the model and, if tracing is enabled, dumps a waveform sample at time. start_clock! calls this for you on every clock edge.

source
VeriJul.Interop.destroy! — Function
destroy!(model)

Frees the C++ model, closes its VCD file and unloads the library. Safe to call more than once. Stop any running clock with stop_clock! first.

source

Simulation

VeriJul.SimCore.Simulator — Type
Simulator(dut::VerilatedModel)

Simulation state for a model: current time, clock value, and the rising_edge/falling_edge conditions testbenches wait on (see @tick). The design must have an input port named clk.

source
VeriJul.SimCore.start_clock! — Function
start_clock!(sim, half_period=5) -> Task

Starts a background task that toggles clk every half_period time units, evaluates the model on each edge and wakes any task waiting in @tick. Throws if the clock is already running.

source
VeriJul.SimCore.stop_clock! — Function
stop_clock!(sim)

Stops the background clock and waits for it to finish. Call this before destroy!-ing the model so the clock never touches freed memory.

source
VeriJul.DSL.@tick — Macro
@tick sim

Pauses the current execution until the next rising edge of the simulator's clock.

source
VeriJul.DSL.@testbench — Macro
@testbench func

Defines func as usual and also a launch_<func>(sim::Simulator) that runs it as an asynchronous task, so it can wait on clock edges with @tick.

@testbench function drive(sim)
    AutoBindings.set_in_data!(sim.dut, 0xFF)
    @tick sim
end

task = launch_drive(sim)
wait(task)
